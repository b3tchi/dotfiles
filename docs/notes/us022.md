# Story [[project-config]] [[product]]

## role
[[pn001|developer]]

## want
see how many claude agents are running in each of my projects and which
state they are in, from one command, without opening every tmux session
to look

## because
agents run in many projects at once and across two accounts, and the
ones that need me — blocked, waiting, failed — are invisible until i
walk the sessions by hand. by the time i notice a blocked agent it has
been idle for hours. i want the counts in one place so whatever renders
my bar, my picker or my status line can show me where the attention is
owed.

## acceptance_criteria
- one command reports, per project, how many agents are idle, working,
  blocked and done
- agents from every configured account are counted, not only the
  account the command happens to run under
- an agent running in a tmux pane is attributed to the project that
  pane belongs to, even when two projects share a filesystem path
- an agent that cannot be attributed to exactly one project is reported
  as unattributed with its working directory shown, never credited to a
  guessed project
- the counts are available as structured output a separate program can
  consume without parsing a rendered table
- the command reports successfully when no agents are running, when
  tmux is not running, and when one of the accounts is absent
- an agent state the command does not recognise is still counted rather
  than dropped from the totals
