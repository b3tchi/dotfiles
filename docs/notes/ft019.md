# Feature [[cat002]] [[product]]

## providing
A libcamera camera source for QML: one C++ Qt6 QML module,
`import LibCamera`, that opens a camera through libcamera directly
(so the `simple` pipeline's software ISP works, where Qt Multimedia's
own `Camera` sees no usable V4L2 device) and pushes its frames into a
Qt Multimedia `QVideoSink`, so any QML `VideoOutput` shows the live
preview. The same import serves a quickshell overlay and a standard
standalone QML app — it is a module, not an app, and owns no UI.
v1 scope ([[sp041]]): list cameras, select one, stream, expose the
display rotation, capture the newest frame to a JPEG path, and
copy the last capture to the clipboard as image/png. Out of scope:
exposure / AE / resolution controls and video recording.

## api_surface
QML (`import LibCamera 1.0`, module dir `LibCamera/` = qmldir + plugin .so +
.qmltypes, found via `QML_IMPORT_PATH`; on the phone
`~/.local/lib/qml`, exported by kwi3's phone session):

- `CameraSource` (QML_ELEMENT)
  - `cameras: list<var>` (read-only) — `{id, name, facing, rotation}` per
    libcamera camera; `facing` back | front | external, `rotation` the
    SENSOR mount (s5kjn1 90, imx471 270).
  - `cameraId: string` — "" picks the first back camera; changing it while
    active switches cameras live.
  - `active: bool` — start / stop streaming (1280x720 RGBA, ~30 fps on the
    Nothing Phone).
  - `videoSink: QVideoSink*` — set from `VideoOutput.videoSink`.
  - `size: size` (read-only) — stream size.
  - `rotation: int` (read-only) — DISPLAY rotation, `(360 - sensor) % 360`
    (270 for the phone's back camera); bind `VideoOutput.orientation` to it.
  - `error: string` (read-only) — "" while streaming; one attempt, never
    retried ("no camera (in use by another app?)" when another PROCESS
    streams — libcamera then enumerates nothing; "camera busy" for a second
    source in the same process; "queue request failed (n)" stops the
    stream). A later successful capture or copy clears it.
  - `capture(path: string)` — the newest frame of the CURRENT stream, turned
    upright by `rotation`, saved as JPEG (q92, parent dirs created, no
    partial file) off the GUI thread; emits `captured(path: string, ok: bool)`.
  - `copyToClipboard()` — the last capture as image/png ([[ft007]] keeps
    only PNG): `wl-copy` on Wayland (no keyboard focus needed), QClipboard
    otherwise.

Phone overlay (quickshell `CameraOverlay.qml`, IPC target `camera`):
`open | snap | close`; via `qs-overlay.sh camera-open | camera-snap |
camera-close`. Driven by hotkeyd's `camera` layer ([[ft011]]): $mod+f opens,
space / Return / f snap, Escape / q close, every key leaves the layer, no
OnExit ([[adr0040]]).

## data_model
No persistent state. Captures are files the caller names; the module
holds only the open camera, its stream config and the newest frame.

## sample
```qml
import QtQuick
import QtMultimedia
import LibCamera 1.0

Item {
    CameraSource {
        id: cam
        active: true
        videoSink: out.videoSink
        onCaptured: (path, ok) => if (ok) cam.copyToClipboard()
    }
    VideoOutput { id: out; anchors.fill: parent; orientation: cam.rotation }
    TapHandler { onTapped: cam.capture("/tmp/shot.jpg") }
}
```

## components
- `b3tchi/libcamera-qml` (private; `~/.local/src/libcamera-qml` on the
  phone): `src/camerasource.{h,cpp}` (libcamera <-> QVideoSink, shared
  CameraManager, stream-generation guard), `src/frameutil.{h,cpp}` (pure
  helpers, unit-tested), `app/main.qml` (standalone app: preview, shutter,
  camera switch), `tests/tst_frameutil.cpp` (ctest), `tests/smoke.qml` and
  `tests/tst_apptaps.qml` (on-device). Built with `QT_NO_KEYWORDS`.
- `camera/dot.yaml` — clone (ff-only main), fresh temp build + ctest, temp
  prefix install, swap into `~/.local/lib/qml/LibCamera`.
- `quickshell/config/CameraOverlay.qml` — layer-shell panel, layer Overlay,
  between the bars (`margins.top: Kwi3Grid.reserve`), no focus, 2-minute
  auto-close; loaded by `shell.qml` through a Wayland-only Loader.
- `quickshell/qs-overlay.sh` — `camera-*` verbs; a failed open clears the
  hotkeyd layer and notifies once.
- `hotkeyd/cmd/hotkeyd/{config,host_phone}.go` — `camera` layer and $mod+f.
- kwi3 `krdp/phone/bin/kwi3-phone-session` — QML_IMPORT_PATH adds
  `~/.local/lib/qml` (kwi3 branch bd-dotfiles-h0hl.5.0).
