# Feature [[cat002]] [[product]]

## providing
A libcamera camera source for QML: one C++ Qt6 QML module,
`import LibCamera`, that opens a camera through libcamera directly
(so the `simple` pipeline's software ISP works, where Qt Multimedia's
own `Camera` sees no usable V4L2 device) and pushes its frames into a
Qt Multimedia `QVideoSink`, so any QML `VideoOutput` shows the live
preview. The same import serves a quickshell overlay and a standard
standalone QML app — it is a module, not an app, and owns no UI.
v1 scope ([[sp041]]): list cameras, select one, stream, expose the
display rotation, capture the newest frame to a JPEG path, and
copy the last capture to the clipboard as image/png. Out of scope:
exposure / AE / resolution controls and video recording.

## api_surface
QML (`import LibCamera 1.0`):

- `CameraSource` (QML_ELEMENT)
  - `cameras: list<var>` (read-only) — `{id, name, facing, rotation}`
    per libcamera camera (`facing`: back | front | external).
  - `cameraId: string` — "" selects the first back camera.
  - `active: bool` — start / stop streaming.
  - `videoSink: QVideoSink*` — set from `VideoOutput.videoSink`.
  - `size: size`, `rotation: int`, `error: string` (read-only).
  - `capture(path: string)` — saves the newest preview frame (stream
    size, 1280x720 by default), rotated upright, as JPEG; emits
    `captured(path: string, ok: bool)`.
  - `copyToClipboard()` — the last capture onto the clipboard as
    image/png (the format the shared clipboard history keeps, [[ft007]]);
    via `wl-copy` on Wayland (works without keyboard focus), QClipboard
    otherwise.

Install: QML module directory `LibCamera/` (qmldir + plugin .so +
.qmltypes) under `~/.local/lib/qml`, found via `QML_IMPORT_PATH`.

## data_model
No persistent state. Captures are files the caller names; the module
holds only the open camera, its stream config and the newest frame.

## sample
```qml
import QtQuick
import QtMultimedia
import LibCamera 1.0

Item {
    CameraSource {
        id: cam
        active: true
        videoSink: out.videoSink
        onCaptured: (path, ok) => if (ok) cam.copyToClipboard()
    }
    VideoOutput { id: out; anchors.fill: parent; orientation: cam.rotation }
    TapHandler { onTapped: cam.capture("/tmp/shot.jpg") }
}
```

## components
- own private repo (libcamera-qml, built on the phone by the
  dotfiles `camera` dot) — C++ module + `app/main.qml` standalone app
- `quickshell/config/CameraOverlay.qml` — the phone overlay consumer,
  driven by hotkeyd's `camera` layer ([[ft011]]) over quickshell IPC,
  hint strip from the mode bar ([[ft009]])
- `camera/dot.yaml` — clone, build and install
