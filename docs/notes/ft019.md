# Feature [[cat002]] [[product]]

## providing
A libcamera camera source for QML: one C++ Qt6 QML module,
`import LibCamera`, that opens a camera through libcamera directly
(so the `simple` pipeline's software ISP works, where Qt Multimedia's
own `Camera` sees no usable V4L2 device) and pushes its frames into a
Qt Multimedia `QVideoSink`, so any QML `VideoOutput` shows the live
preview. The same import serves a quickshell overlay and a standard
standalone QML app — it is a module, not an app, and owns no UI.
v1 scope ([[sp041]]): list cameras, select one, stream, expose the
display rotation, capture the newest frame to a JPEG path, and
copy the last capture to the clipboard as image/png. Widened by
[[sp045]]: lens focus (the lens V4L2 subdev, [[sp044]]) and manual
exposure (time x gain as request controls, stills included). Out of
scope: resolution controls, autofocus and video recording.

## api_surface
QML (`import LibCamera 1.0`, module dir `LibCamera/` = qmldir + plugin .so +
.qmltypes, found via `QML_IMPORT_PATH`; on the phone
`~/.local/lib/qml`, exported by kwi3's phone session):

- `CameraSource` (QML_ELEMENT)
  - `cameras: list<var>` (read-only) — `{id, name, facing, rotation}` per
    libcamera camera; `facing` back | front | external, `rotation` the
    SENSOR mount (s5kjn1 90, imx471 270).
  - `cameraId: string` — "" picks the first back camera; changing it while
    active switches cameras live.
  - `active: bool` — start / stop streaming (1280x720 RGBA, ~30 fps on the
    Nothing Phone).
  - `videoSink: QVideoSink*` — set from `VideoOutput.videoSink`.
  - `size: size` (read-only) — stream size.
  - `rotation: int` (read-only) — DISPLAY rotation, `(360 - sensor) % 360`
    (270 for the phone's back camera); bind `VideoOutput.orientation` to it.
  - `error: string` (read-only) — "" while streaming; one attempt, never
    retried ("no camera (in use by another app?)" when another PROCESS
    streams — libcamera then enumerates nothing; "camera busy" for a second
    source in the same process; "queue request failed (n)" stops the
    stream). A later successful capture or copy clears it.
  - `capture(path: string)` — a full still: the viewfinder pauses, the
    stream is reconfigured as StillCapture at `stillSize`, 4 settle frames,
    then back to the viewfinder; the frame is turned upright by `rotation`
    and saved as JPEG (q92, parent dirs created, no partial file) off the
    GUI thread; emits `captured(path: string, ok: bool)`. With `stillSize`
    0x0 it saves the newest viewfinder frame and notes it in `error`
    ([[sp042]]).
  - `capturing: bool` (read-only) — true while a still pauses the preview.
  - `stillSize: size` (read-only) — the largest still size strictly below
    the sensor mode (3840x2880 on the s5kjn1, [[poc027]]); 0x0 if none.
  - `copyToClipboard()` — the last capture as image/png ([[ft007]] keeps
    only PNG), scaled to a 2048 long side and encoded off the GUI thread:
    `wl-copy` on Wayland (no keyboard focus needed), QClipboard otherwise.
  - Focus ([[sp045]]): `focusAvailable: bool` (ro; a lens subdev answering
    QUERYCTRL focus_absolute was found and opened at start),
    `focusPosition: int` (ro, readback, -1 unavailable), `focusDefault: int`
    (set on every start and again on stop; -1 leaves the lens alone),
    `focusNear()` / `focusFar()` (one rung on a dioptre ladder from the far
    default: code = far + 18.9 x D), `focusReset()`. A failing ioctl sets
    `error` once and turns focus off until the next start.
  - Exposure ([[sp045]]): `autoExposure: bool` (rw; every start begins in
    auto), `exposureTime: int` (us) / `analogueGain: real` (ro, from frame
    metadata in both modes), `exposureLimit: bool` (ro, last step cut by a
    limit), `brighter()` / `darker()` (1/3 stop of time x gain; time first
    going brighter, gain first going darker; in auto they first switch to
    manual seeded from the last metadata). Manual controls ride every
    request, stills too, with FrameDurationLimits pinned to the time (on the
    s5kjn1 viewfinder ExposureTime ends at 33152 us, so it never lengthens).
  - Calibration and carry-over ([[sp046]]): `focusSlope: real` (rw,
    codes per dioptre, default 12.9; the ladder is far + slope x D),
    `focusDioptres: real` (rw, focus as a distance), `setExposureTime(us)`
    (manual, clamped), `setIso(iso)` (0 = auto, nearest supported rung),
    `colourGains: list<real>` (ro, [r, b] of free-running AWB) and
    `setColourGains(r, b)` (carried into the next configure's AWB lock and
    hold).

Phone overlay (quickshell `CameraOverlay.qml`, IPC target `camera`):
`open | snap | close | near | far | refocus | auto | brighter | darker`;
via `qs-overlay.sh camera-<verb>`. Driven by hotkeyd's `camera` layer
([[ft011]]): $mod+f opens, n / Alt+n nearer / farther, d far focus, a auto
/ manual, e / Alt+e brighter / darker (step keys stay in the layer), space
snaps (only space, since 2026-11-28) and Escape / q close (terminal keys leave it), no OnExit
([[adr0041]]); l / Alt+l / Ctrl+l switch cameras with the shot settings
carried over ([[sp046]]). The overlay shows F / AE (and "capturing…") bottom-left over
the picture; the bar's camera strip lists the keys. It owns kwi3's mode
from the snap / quit key until it closes ([[adr0042]]) and closes itself
if hotkeyd's state feed ends.

## data_model
No persistent state. Captures are files the caller names; the module
holds only the open camera, its stream config and the newest frame.

## sample
```qml
import QtQuick
import QtMultimedia
import LibCamera 1.0

Item {
    CameraSource {
        id: cam
        active: true
        videoSink: out.videoSink
        onCaptured: (path, ok) => if (ok) cam.copyToClipboard()
    }
    VideoOutput { id: out; anchors.fill: parent; orientation: cam.rotation }
    TapHandler { onTapped: cam.capture("/tmp/shot.jpg") }
}
```

## components
- `b3tchi/libcamera-qml` (private; `~/.local/src/libcamera-qml` on the
  phone): `src/camerasource.{h,cpp}` (libcamera <-> QVideoSink, shared
  CameraManager, stream-generation guard), `src/frameutil.{h,cpp}` (pure
  helpers, unit-tested), `app/main.qml` (standalone app: preview, shutter,
  camera switch), `src/controlutil.{h,cpp}` (focus / exposure ladders,
  meanLuma), `src/lens.{h,cpp}` (LensControl: V4L2 subdev focus),
  `tests/tst_frameutil.cpp`, `tests/tst_controlutil.cpp`, `tests/tst_lens.cpp`
  (ctest; tst_lens needs LCQ_EXPECT_LENS=1 on a device with a lens),
  `tests/smoke.qml`, `tests/focus_smoke.{qml,sh}`,
  `tests/exposure_smoke.{qml,sh}` + `tests/lumamean.cpp` and
  `tests/tst_apptaps.qml` (on-device). Built with `QT_NO_KEYWORDS`.
- `camera/dot.yaml` — clone (ff-only main), fresh temp build + ctest, temp
  prefix install, swap into `~/.local/lib/qml/LibCamera`.
- `quickshell/config/CameraOverlay.qml` — layer-shell panel, layer Overlay,
  between the bars (`margins.top: Kwi3Grid.reserve`), no focus, 2-minute
  auto-close; loaded by `shell.qml` through a Wayland-only Loader.
- `quickshell/qs-overlay.sh` — `camera-*` verbs; a failed open clears the
  hotkeyd layer and notifies once; a failed step does not.
- `quickshell/config/Common/CameraReadout.js` — F / AE / capturing text
  (tests: `quickshell/test-camera-readout.sh`).
- `quickshell/config/Common/ModeBarTheme.qml` — camera / camera-reverse key
  strips, `cameraActive` (bar shows camera mode while the preview is up).
- `hotkeyd/cmd/hotkeyd/{config,host_phone}.go` — `camera` layer and $mod+f.
- kwi3 `krdp/phone/bin/kwi3-phone-session` — QML_IMPORT_PATH adds
  `~/.local/lib/qml` (kwi3 branch bd-dotfiles-h0hl.5.0).
