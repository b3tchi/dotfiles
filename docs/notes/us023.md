# Story [[project-config]] [[product]]

## role
[[pn001|developer]]

## want
see the agent counts without running a command — in the bar I already
have on screen, and in the picker I already use to switch projects

## because
[[ft012]] answers the question but only when i think to ask it, and the
agents that need me are exactly the ones i am not thinking about. a
background agent blocked for three months is invisible precisely
because nothing prompts me to go looking. the counts are only worth
gathering if something surfaces them where i already look.

## acceptance_criteria
- the project picker shows, per project, how many agents are waiting on
  me, so the choice of where to go carries that information
- a bar widget shows the count of agents needing attention across all
  projects, updating without me asking
- neither consumer re-implements the join; both read the published
  structured output
- a consumer that polls does not pay the full probe cost on every
  refresh — the census takes ~600 ms, dominated by one claude call per
  account, which is fine on demand and wrong on a timer
