# PoC [[cat002]] [[board]]

## informs
[[sp042|us026-full-resolution-still]]

## hypothesis
On the Nothing Phone's back camera (s5kjn1, libcamera 0.8 `simple`
pipeline, one stream only), stopping the 1280x720 viewfinder,
reconfiguring the single stream as StillCapture 4080x3072, dropping a few
AE settle frames, grabbing one, reconfiguring back to the viewfinder and
saving an upright JPEG fits the us026 budget of <= 6 s, and the still is
exposed at least as well as the viewfinder.

## method
Scratch C++ program (discarded) against libcamera 0.8.0 + Qt 6.12 on the
phone, 2026-11-22: viewfinder 30 frames -> stop -> StillCapture 4080x3072
ABGR8888 -> settle N (2/4/10/20) -> grab -> stop -> viewfinder -> rotate
270 -> JPEG q92; PNG encode variants for the clipboard; optional carry-over
of the viewfinder's ExposureTime/AnalogueGain as manual controls. Mean
luma (64x64 downscale) of viewfinder vs still. Built with QT_NO_KEYWORDS.

## result
validated (mechanics + timing); image quality in good light NOT judged
(room dark at test time: viewfinder luma ~10 at max gain 64).
- phases: stop vf ~55 ms, still start ~370 ms, settle 4 + grab ~660 ms,
  stop still ~120 ms, viewfinder back + first frame ~225 ms, rotate ~50 ms,
  JPEG 12.5 MP ~225 ms => capture() -> JPEG saved ~1.6-1.8 s (settle 2-4),
  2.3 s (10), 3.3 s (20). Output 3072x4080 upright.
- exposure: still luma 21-24 vs viewfinder ~10 for every settle count and
  with/without carry-over -> AE does not need more than 4 settle frames
  here; carry-over brings nothing.
- clipboard PNG: full 12.5 MP 6.6 s / 17.7 MB (q-1), 0.4 s / 36 MB (q100);
  1536x2040 0.44 s / 6.5 MB (q-1), 0.11 s / 9 MB (q100).
- no dual stream: viewfinder + still pair rejected by the pipeline.

## recommendation
Adopt [[sp042]]'s reconfigure approach with 4 settle frames, no exposure
carry-over. Clipboard: copy a 2048-long-side PNG (fast compression),
encoded OFF the GUI thread, keep the full-size JPEG on disk — a full-size
PNG would freeze the overlay ~7 s. Re-check exposure in daylight during
work-do (smoke + a bright-scene still).
