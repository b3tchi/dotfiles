# Implementation [[cat002]] [[product]]

## solves
[[us028|ultrawide-lens-focus-control]]

## approach
Drive the ultrawide's Dongwoon DW98xx focus actuator with the mainline
`dw9719` driver ([[poc028]], [[poc029]]): a device-tree `actuator@c`
(`dongwoon,dw9800k`) on the s5kjn1's CCI bus, powered from the existing
`vreg_camu_vaf_1p8` with a startup delay, linked to the sensor with
`lens-focus`. A udev rule parks the lens at the infinity code (377) on
every bind. A patched `dw9719` (out-of-tree kmod build) powers the VCM
only while the sensor streams, through a runtime-PM device link, instead
of while the subdev is open. Apps focus through the lens's V4L2 subdev
(`focus_absolute`, no root). Exposure: manual time / gain work today; a
carried softISP AGC patch makes `ExposureValue` effective.

## features
- [[ft019]] (unchanged; must keep working)

## data_model
No persistent state. One constant: the infinity code 377 in the udev
rule ([[poc028]] fit `pos = 377 + 18.9/m`).

## api_surface
- Lens: `/dev/v4l-subdevN` named `dw9719 18-000c`, control
  `focus_absolute` 0-1023 (group `video`).
- libcamera: `ExposureValue` honoured with AE on; `ExposureTime` /
  `AnalogueGain` with AE off.
