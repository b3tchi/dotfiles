# ADR [[cat002]] [[cat001]] [[product]]

## title
hotkeyd external control compile time declared

## title
hotkeyd external control stays compile-time-declared and
channel-separated, never a generic write API

## context
[[sp023]] needed a way for a mouse-driven process (quickshell's
screenshot-drag overlay) to set hotkeyd's layer state, since hotkeyd's
engine only reacts to X11 chords and nothing external could poke its
state. [[adr0012]] already frames hotkeyd's existing state socket as a
singleton-daemon / read-only-consumers channel (bars, focus-border,
read only). The natural-looking shortcut was to add a write path to
THAT socket, or to expose a generic RPC verb accepting an arbitrary
layer name from any caller.

## decision
External control of hotkeyd stays two things at once: COMPILE-TIME
declared and CHANNEL-separated.

- A layer must be declared `External: true` in the compiled bind table
  ([[adr0021]]'s compile-time-validation discipline extended to this
  surface) before ANY external process may ever set it. There is no
  \"register a layer at runtime\" path, at the daemon or the CLI.
- The write lives on a NEW, separate control socket
  (`hotkeyd-<n>-ctl.sock`), never on the existing state socket. The
  state socket keeps never reading client bytes, so [[adr0012]]'s
  framing stays literally true for every layer that existed before this
  spec — this is a narrow, named exception bolted alongside it, not a
  loosening of it.
- The daemon revalidates every request against its OWN compiled table
  regardless of what the CLI already checked, and refuses by name any
  request while a chord-entered layer is active — an external process
  can set a SIGNAL, never seize control a human already holds.

## consequences
A future capability needing to notify hotkeyd from outside the X11
event stream (another mouse-driven overlay, a systemd unit, a script)
follows this same shape: declare the layer External in source, dial the
control socket, never patch a write path into the state socket. This
forecloses the alternative of a general-purpose RPC surface on hotkeyd
-- every future external trigger costs a compiled-in declaration, which
is the tax [[adr0021]] already charges for every ordinary bind. The
state socket's read-only guarantee ([[adr0012]]) is now something a
future engineer can rely on by construction: no code path anywhere in
the daemon reads from it, and this ADR is the citable reason no one
should add one to save an extra socket.
