# Implementation [[cat002]] [[product]]

## solves
[[us030|camera-keyboard-focus-exposure]]

## approach
hotkeyd's `camera` layer ([[ft011]]) gains step keys that stay in the
layer ([[adr0041]], superseding [[adr0040]]) and send IPC verbs to
quickshell's CameraOverlay; the overlay drives the LibCamera QML module
([[ft019]]), which owns focus (the lens V4L2 subdev, [[sp044]]) and
manual exposure (libcamera request controls, carried into stills).
Every camera start and stop resets far focus and auto-exposure, so no
OnExit is needed.

## features
- [[ft019]] (extended: focus + exposure API)
- [[ft011]] (camera layer step keys)
