# Implementation [[cat001]] [[product]]

## solves
[[us024|scrape-film-artwork]]

## approach
A pair of Nushell entry points wraps TMDb APIs directly: one helper selects a
TMDb id for MediaElch, while the full scraper fetches movie details, renders a
Kodi movie NFO, and downloads available film artwork to MediaElch/Kodi sidecar
names. The implementation deliberately avoids MediaElch's SQLite database and
only writes files beside the selected movie.

## features

## data_model
No persistent application state is owned. Runtime inputs are the target movie
path, optional title/year, TMDb API key, optional fanart.tv credentials, and the
selected TMDb result. Outputs are sidecar files under the movie directory.

## api_surface
- `mediaelch-tmdb [name] [year]` prints a MediaElch `idNNN` token after fuzzy
  TMDb selection.
- `mediaelch-scrape <movie-file-or-folder> [name] [year]` writes full movie
  sidecars.
- `--dry-run` prints planned writes; `--first` bypasses fuzzy selection;
  `--json` is available on the id picker.
- `FANARTTV_API_KEY` or `--fanarttv-api-key` enables richer clearlogo,
  clearart, discart, banner, and extra-fanart downloads when available.
