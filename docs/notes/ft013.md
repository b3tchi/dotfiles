# Feature [[cat001]] [[product]]

## providing

A single runtime-neutral lifecycle contract consumed by Infinifu idea, spec,
work, audit, merge, and retrospective skills while retaining native behavior
for both Claude Code and Pi.

## api_surface

Lifecycle stages continue to invoke their existing skill names. The contract
itself lives in one file — `skills/meta-patterns/runtime-adapter.md` — and
skills cite that reference rather than restating the rule, so a new runtime
branch is added in one place.

Runtime selection is explicit and ordered: `AI_AGENT=pi` selects Pi behavior;
availability of Claude's native agent surface selects Claude behavior; no match
fails closed with an `unsupported-runtime` error naming the lifecycle operation
that cannot proceed. Falling through to a partial adapter is not an outcome.

Idea, spec, and other AKM stages receive direct instructions and resolve
artifact IDs through `akm`. A `work-*` subagent's direct work-content payload is
only its bd ticket ID; it resolves the task contract through `bd show <id>`.
Direct messaging remains the primary control channel. Under Pi, [[ft014]]
provides that channel through a worker CLI message bus. Tmux remains only the
display and process host.

A delegated stage may report completion only after its own required validation
passes; its compact return carries the result, validation verdict, visible
worker name, and exact resume command. Validation that fails or cannot run
returns blocked or failed, never complete.

Lifecycle shape is dual. Story-backed specs keep their source `us###` and
consumed `im###` and their story acceptance criteria stay binding. Feature-add
specs deliver a proposed `ft###` with no story or implementation lineage, and no
stage may fabricate one to fit the story-backed path. Lineage is read only from
the declaring sections per [[adr0026]].

Claude Code keeps named background subagent dispatch, completion notifications,
and resume/stop semantics on its branch. Pi runs lifecycle stages sequentially
until an explicit multi-worker adapter is installed; a multi-worker request
under Pi reports unsupported and defers to [[sp028]] rather than claiming a
Claude dispatch occurred. The Claude agent census [[ft012]] is not a runtime
detector ([[adr0024]], [[adr0025]]).

## data_model

Stateless. Durable lifecycle state remains in AKM zettels, bd/Dolt, Git, and
the active agent harness's session store.

## sample

```text
request: refine sp027
skill:   spec-refinement
AKM:     akm read sp027
runtime: pi
result:  same lifecycle transition and artifacts as Claude Code
```

The contract is executable: one command runs every suite that guards it and
exits nonzero on any failure.

```console
$ bash claude/marketplace/plugins/infinifu/skills/lifecycle-contract-workspace/run-lifecycle-validation.sh
PASS     lifecycle-contract-workspace/test_runtime_selection_contract.py (Ran 8 tests)
PASS     lifecycle-contract-workspace/test_feature_add_lifecycle_contract.py (Ran 7 tests)
PASS     plan-scrum-master-workspace/test_orchestration_runtime_contract.py (Ran 6 tests)
PASS     work-lineage-workspace/test_work_lineage_contract.py (Ran 5 tests)
PASS     work-merge-workspace/test_archive_epic.py (Ran 7 tests)
PASS     spec-retro-workspace/test_feature_add_retro_grader.py (Ran 2 tests)
```
