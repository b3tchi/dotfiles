# Feature [[cat001]] [[product]]

## providing

A single runtime-neutral lifecycle contract consumed by Infinifu idea, spec,
work, audit, merge, and retrospective skills while retaining native behavior
for both Claude Code and Pi.

## api_surface

Lifecycle stages continue to invoke their existing skill names. Idea, spec,
and other AKM stages receive direct instructions and resolve artifact IDs from
the AKM documents through `akm`. A `work-*` subagent's direct work-content
payload is only its bd ticket ID; it resolves the task contract through
`bd show <id>`. Direct messaging remains the primary control channel. Under
Pi, [[ft014]] provides that channel through a worker CLI message bus. Tmux
remains only the display and process host. A delegated stage may report
completion only after its own required validation passes, and its compact
return includes the result,
validation verdict, visible worker name, and exact resume command. Git remains
authoritative for source state. Runtime selection is explicit:
`AI_AGENT=pi` selects Pi behavior; availability of Claude's native agent
surface selects Claude behavior; no match returns an
unsupported-runtime error. Multi-worker operations are a separate capability
and may report unsupported until their runtime adapter is installed.

## data_model

Stateless. Durable lifecycle state remains in AKM zettels, bd/Dolt, Git, and
the active agent harness's session store.

## sample

```text
request: refine sp027
skill:   spec-refinement
AKM:     akm read sp027
runtime: pi
result:  same lifecycle transition and artifacts as Claude Code
```
