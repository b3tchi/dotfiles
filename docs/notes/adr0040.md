# ADR [[cat002]] [[product]]

## title
A hotkeyd layer that drives an external overlay exits on its own keys and has no OnExit

## context
sp041 put the phone camera behind a hotkeyd chord layer (`camera`, entered by
$mod+f, [[ft011]]) whose keys drive quickshell's CameraOverlay over IPC
([[ft019]]). Two natural designs failed in audit (dotfiles-h0hl.7):

1. Snap keys run `camera-snap` + ExitLayer, with OnExit `camera-close`. The
   engine dispatches OnExit in the same instant as the key's own Run, so close
   raced snap and won: photos not copied or announced, sometimes not taken.
2. Snap keys stay in the layer and the overlay ends it with
   `hotkeyd set-layer default`. Refused: a chord-entered layer outranks any
   external set-layer request, including a clear ([[adr0022]]'s contract,
   engine.go SetExternalLayer). The keys stayed grabbed after the photo.

## decision
A hotkeyd chord layer whose keys hand work to an external process (an
overlay, a picker) ends on its own keys - each key runs its command AND
ExitLayer - and declares NO OnExit that talks to the same process. The
external process owns its own safety net for an involuntary exit (hotkeyd
killed at screen lock, daemon restart): for CameraOverlay a 2-minute
auto-close. hotkeyd's external control stays as [[adr0022]] decided:
external processes never clear a chord-entered layer.

User decision 2026-11-22 ("Drop auto-close"), chosen over widening the
control socket (`set-layer default --from <layer>`, an adr0022 change) and
over a delayed close (timing-dependent).

## consequences
- No race between a key's command and an exit command: one key, one message.
- The keyboard is handed back the moment the key is pressed, even if the
  external work then fails (the overlay shows its error; $mod+f re-enters).
- An involuntary exit leaves the external UI up until its own timeout
  (2 minutes for the camera) or the user re-enters the layer and closes it.
- Tests pin it at the engine level (hotkeyd TestCameraKeysDispatch drives
  layer.NewEngine: one key -> exactly one command, layer back to default).
- Other layers keep OnExit where the external side is idempotent and nothing
  else is in flight (the switcher's switcher-cancel).
