# Feature [[cat001]] [[cat002]] [[product]]

## providing

One clipboard across every host on the LAN, carried by a transport this repo
owns. A single `clipd hub` per user orders and fans out clipboard entries;
each host runs a `clipd agent` that pushes local copies and applies remote
ones, bidirectionally. Every entry is treated as a secret: payloads are
AES-256-GCM encrypted end to end between agents (shared per-user key from
gopass, [[ft015]]), so the hub relays ciphertext it cannot read. Nothing is
persisted, every entry carries a TTL, and agents clear the local clipboard
when the synced value expires. Network reach is SSH only — no TCP listener
anywhere. History is NOT provided here; it stays with [[ft007]].

## api_surface

One Go binary, subcommands:

    clipd hub                      serve $XDG_RUNTIME_DIR/clipd.sock (0600)
    clipd pipe                     bridge stdio <-> local clipd.sock
                                   (remote agents: `ssh <hub> clipd pipe`)
    clipd agent x <display>        X CLIPBOARD agent, display named explicitly
    clipd agent windows            Win32 clipboard agent (history/cloud excluded)
    clipd agent termux             termux-clipboard-get/set agent
    clipd agent qml                decrypted per-session stream for Quickshell
    clipd status                   per-agent last hub round-trip + link state

Wire: JSON lines over the socket / ssh stdio.

    -> {op:"hello", origin, proto}
    -> {op:"set", origin, id, mime, ttl, nonce, ct}
    -> {op:"sub"}
    <- {op:"event", seq, origin, id, mime, ttl, nonce, ct}
    <> {op:"ping"|"pong", t}

## data_model

Hub state (memory only): current unexpired entry + seq counter + subscriber
set. Entry = {seq, origin, id, mime ∈ {text/plain;charset=utf-8, image/png},
size ≤ cap, ttl, nonce, ct}; GCM AAD binds seq-independent metadata
(origin, id, mime, ttl, size). Agent state: key (memory), hash of last
applied payload (echo suppression), last round-trip time.

## sample

    # hub host
    clipd hub &
    # another LAN host
    clipd agent x :0 --hub ssh://linuxbox
    # Windows (scheduled task at logon)
    clipd.exe agent windows --hub ssh://linuxbox
