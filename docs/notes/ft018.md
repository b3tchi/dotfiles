# Feature [[cat001]] [[cat002]] [[product]]

## providing

Clipboard sharing across every host on the LAN with the **native clipboard
as the source of truth**. Each host runs a `clipd agent`: when the user
copies, the agent writes an age-encrypted entry into a Syncthing folder;
entries from other hosts stay encrypted there and are offered in the
`$mod+v` picker, decrypted only when picked and then published to the
native clipboard. Paste never involves clipd. Every entry is a secret:
per-device age identities, recipients pinned locally, short TTL, Linux
folder on tmpfs, password-manager-marked copies never written. Peer-to-peer
over Syncthing (LAN only) — no hub, no always-on host. History is NOT
provided here; it stays with [[ft007]]. Delivered by [[sp039]].

## api_surface

One Go binary:

    clipd agent x <display>     watch X CLIPBOARD, write encrypted entries
                                (display named explicitly, bounded reads)
    clipd agent windows         same for the Win32 clipboard
    clipd agent termux          (deferred — follow-up spec)
    clipd list                  remote entries, decrypted in memory:
                                "<id>\t<origin>\t<age>\t<preview>"
    clipd pick <id> [display]   decrypt <id>, publish to native clipboard
    clipd status                per-peer heartbeat last-seen + Syncthing link
    clipd keygen                create this device's age identity
    clipd recipients add|rm     manage the locally pinned recipient list

`$mod+v` → `qs-clip.sh toggle` merges [[ft007]] local history with
`clipd list`; picking a remote entry calls `clipd pick`. On Windows the
surface is CLI-only for now (`clipd.exe list | pick <id> | pick --latest`);
the same Quickshell picker arrives there via kwi3. The X agent drives
`clipnotify` / `xclip` (every call time-bounded); the Windows agent uses
Win32 directly ([[poc024]]). Linux user wrapper: `nushell/actions/clipd.nu`
(`setup | peer add | peer rm | status | start | stop`).

## data_model

Sync folder: one file per entry, `<random-id>.age`, age-encrypted to all
pinned recipients. Plaintext inside: `{origin, created, ttl, mime, size,
data}` with mime ∈ {text/plain;charset=utf-8, image/png}. Heartbeats:
`hb-<device>.age`. Local per device: identity file (0600, never synced),
recipient list, last-written hash (echo suppression). No plaintext is
written anywhere.

## sample

    clipd keygen                        # once per device
    clipd recipients add age1...        # each peer's public key
    clipd agent x :40 &                 # copy here -> encrypted entry
    # on another host: $mod+v, pick the entry -> native clipboard
